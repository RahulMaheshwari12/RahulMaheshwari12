## 🚀 Featured Projects

### 🫀 [Heart Disease Risk Prediction — PyTorch ANN](https://github.com/RahulMaheshwari12/Heart-Disease-Risk-Prediction-PyTorch-ANN)
> End-to-end heart disease prediction on 630,000 patient records

- 🗄️ **SQLite3 data pipeline** with 16 SQL queries for EDA
- 🔧 **Feature engineering** — 3 domain-driven features
- 🤖 **PyTorch ANN** with BatchNorm, Dropout & WeightedRandomSampler
- 🎯 **ROC-AUC: 0.9537** — beats Logistic Regression baseline (0.9515)
- 🌐 Deployed as **Flask web application**
- ⚕️ Threshold tuned at **0.4 for 91% recall** — medical context
